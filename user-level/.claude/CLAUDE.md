# General rule: never guess

- If you don't have enough context to answer or act correctly, **don't guess**.
- In that case, do one of these two things:

1. **Ask me precise questions** to fill in the missing information.
2. **Give me proposals** (clear options, with a recommendation) and let me choose.

# General rule: use existing code

- Don't invent files, APIs, behaviors, requirements, or intentions to fill a gap. Search the codebase for already existing code, variables, services, behaviors, helpers etc.
